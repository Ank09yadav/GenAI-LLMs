## 28. What is next-token prediction?

### Answer

**Next-token prediction** (also known as autoregressive language modeling) is the core operational mechanism and training objective of modern decoder-only Large Language Models. Given a sequence of preceding tokens $(x_1, x_2, \dots, x_{t-1})$, the model computes a probability distribution over the entire vocabulary $V$ to predict the most likely token at position $t$:

$$P(x_t \mid x_1, x_2, \dots, x_{t-1})$$

```text
                           The Next-Token Prediction Pipeline
                           
 Context Tokens:
 ["The", "capital", "of", "France", "is"]
                  │
                  ▼
 ┌────────────────────────────────────────────────────────┐
 │ Transformer Layers (Self-Attention + Causal Masking)   │
 └────────────────────────┬───────────────────────────────┘
                          │ Hidden state vector h_t ∈ R^d
                          ▼
 ┌────────────────────────────────────────────────────────┐
 │ Linear Output Head (Unembedding Matrix W_u ∈ R^|V| x d)│
 └────────────────────────┬───────────────────────────────┘
                          │ Raw Logits z_t ∈ R^|V| (e.g., 128,000 vocab)
                          ▼
 ┌────────────────────────────────────────────────────────┐
 │ Softmax Layer: P(v) = exp(z_v) / Σ exp(z_j)            │
 └────────────────────────┬───────────────────────────────┘
                          │ Probability Distribution over Vocabulary
                          ▼
                 "Paris"  : 0.942
                 "Lyon"   : 0.021
                 "located": 0.011
                 "the"    : 0.008
```

### The Profound Paradox: Why Simple Autoregression Generates "Intelligence"

A common initial skepticism is: *How can a statistical system that merely guesses the next token write software, solve calculus, compose poetry, and summarize legal contracts?*

The theoretical answer, articulated prominently by AI researchers like Ilya Sutskever, is that **accurate next-token prediction over human text is impossible without internalizing the underlying data-generating process of the real world.**

Consider predicting the final token in these examples:

1. **Physical Commonsense:**
   > *"He dropped the glass mug onto the granite countertop, and it \_\_\_\_"*  
   > To predict `"shattered"`, the model must simulate Newtonian mechanics, material brittleness, and gravitational acceleration.

2. **Deductive Logic & Theory of Mind:**
   > *"Alice hid the key in the blue drawer. Bob entered the room and watched Alice move it to the red box. When Alice leaves, Bob will look for the key in the \_\_\_\_"*  
   > To predict `"red"`, the model must maintain separate mental models of Alice's beliefs versus Bob's observations.

3. **Algorithmic Simulation (Code):**
   > `def add(a, b): return a + b`  
   > `print(add(15, 27)) # Output: `  
   > To predict `"42"`, the model cannot simply memorize text; it must execute arithmetic operations within its intermediate latent layers.

Compression of information is equivalent to intelligence. To compress human knowledge down to a model with finite parameters and predict the next token with high accuracy, the network is forced to learn generalizable world models, causal structures, and grammatical hierarchies.

### Mathematical Walkthrough of Next-Token Prediction

The exact computational step for position $t$ proceeds as follows:

1. **Token Input & Context Representation:**
   The prefix tokens $X_{<t} = [x_1, \dots, x_{t-1}]$ pass through the embedding layer and $L$ Transformer blocks.
2. **Hidden State Extraction:**
   At the final layer $L$, the output hidden vector corresponding to the last token position is extracted:
   $$\mathbf{h}_{t-1} \in \mathbb{R}^{d_{\text{model}}}$$
3. **Logit Projection:**
   $\mathbf{h}_{t-1}$ is multiplied by the unembedding weight matrix $W_u \in \mathbb{R}^{|V| \times d_{\text{model}}}$:
   $$\mathbf{z}_t = W_u \mathbf{h}_{t-1} + \mathbf{b}_u \quad (\mathbf{z}_t \in \mathbb{R}^{|V|})$$
4. **Softmax Normalization:**
   The raw logit scores $\mathbf{z}_t$ are transformed into a normalized probability distribution:
   $$P(x_t = v \mid X_{<t}) = \frac{\exp(z_{t, v})}{\sum_{j \in V} \exp(z_{t, j})}$$
5. **Loss Computation (During Training):**
   If the true ground-truth token in the training text is $x_t^*$, the cross-entropy loss for this position is:
   $$\mathcal{L}_t = -\log P(x_t = x_t^* \mid X_{<t})$$

### Training vs. Inference: Parallelism vs. Autoregressive Loop

A key difference lies in how next-token prediction operates during training versus generation:

| Dimension | Training Mode (Teacher Forcing) | Inference / Generation Mode |
| :--- | :--- | :--- |
| **Execution** | **Fully Parallel:** All $T$ tokens in a sequence are fed simultaneously. Causal masking ensures position $i$ only attends to positions $\le i$. | **Sequential / Recurrent:** The model generates one token at a time, appends it to the prompt, and loops. |
| **Speed** | Extremely fast ($O(1)$ forward passes per training sequence of length $T$). | Slower ($O(T)$ forward passes to produce $T$ new tokens). |
| **Input Feedback** | Ground-truth tokens are always provided as context ("Teacher Forcing"). | The model consumes its own generated tokens ("Closed Loop"), which can accumulate errors. |

---

### Key Point

> **Next-token prediction is the autoregressive objective where a model predicts the probability distribution of the subsequent token given past context. Because predicting human text with high accuracy demands deep world modeling, this seemingly simple objective forces the network to learn logic, physics, coding, and abstract reasoning.**

---

### Interview Answer

> "Next-token prediction is the foundational self-supervised objective of autoregressive language models. At each token position, the model projects the final hidden state across an unembedding matrix to produce a probability distribution over the vocabulary via softmax.
> 
> While superficially an autocomplete task, accurate next-token prediction requires the model to develop internal representations of the real-world processes that created the text—including physical laws, algorithmic execution, grammatical syntax, and multi-step reasoning. During training, all positions are trained in parallel using causal masking and teacher forcing, whereas at inference, generation is an autoregressive sequential loop."
