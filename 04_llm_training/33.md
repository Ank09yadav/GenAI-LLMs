## 33. What is RLHF (Reinforcement Learning from Human Feedback)?

### Answer

**Reinforcement Learning from Human Feedback (RLHF)** is an alignment framework designed to steer Large Language Models toward human values, preferences, and safety guidelines—encapsulated by the **HHH Criteria** (Helpful, Honest, and Harmless).

While Supervised Fine-Tuning (SFT) teaches the model *how* to answer, human evaluators frequently disagree on what constitutes the "best" response among several correct options. Furthermore, ranking responses is cognitively easier and far less ambiguous for humans than writing perfect demonstration responses from scratch. RLHF utilizes human preference comparisons to optimize the model's generation policy.

```text
                                  The 3-Phase RLHF Pipeline
                                  
 ┌─────────────────────────────────────────────────────────────────────────────────────────────┐
 │ Phase 1: Supervised Fine-Tuning (SFT)                                                       │
 │ Train initial base model on curated prompt-response pairs to obtain baseline policy π^SFT.  │
 └──────────────────────────────────────────────┬──────────────────────────────────────────────┘
                                                │
                                                ▼
 ┌─────────────────────────────────────────────────────────────────────────────────────────────┐
 │ Phase 2: Reward Model (RM) Training                                                         │
 │ 1. Sample multiple completions (y_1, y_2, y_3, y_4) for a prompt x from π^SFT.              │
 │ 2. Human annotators rank completions: y_1 > y_2 > y_3 > y_4.                                │
 │ 3. Train Reward Model r_ψ(x, y) using Bradley-Terry preference loss.                        │
 └──────────────────────────────────────────────┬──────────────────────────────────────────────┘
                                                │
                                                ▼
 ┌─────────────────────────────────────────────────────────────────────────────────────────────┐
 │ Phase 3: Policy Optimization via PPO                                                        │
 │ Optimize actor model π_θ to maximize reward r_ψ while penalizing KL-drift from π^SFT.       │
 └─────────────────────────────────────────────────────────────────────────────────────────────┘
```

---

### Phase 2: The Reward Model & The Bradley-Terry Objective

The Reward Model $r_\psi(x, y)$ is a Transformer initialized from the SFT model, with its final unembedding head replaced by a scalar regression head that outputs a single floating-point score for any prompt-completion pair.

Pairs of completions $(y_w, y_l)$ are constructed where human annotators preferred $y_w$ (winner) over $y_l$ (loser). The probability of choosing $y_w$ over $y_l$ is modeled using the **Bradley-Terry preference model**:

$$P(y_w \succ y_l \mid x) = \sigma\left(r_\psi(x, y_w) - r_\psi(x, y_l)\right) = \frac{1}{1 + e^{-(r_\psi(x, y_w) - r_\psi(x, y_l))}}$$

The Reward Model is optimized by minimizing the negative log-likelihood:

$$\mathcal{L}_{\text{RM}}(\psi) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma\left( r_\psi(x, y_w) - r_\psi(x, y_l) \right) \right]$$

---

### Phase 3: The PPO Training Loop & 4-Model System

Optimizing the policy $\pi_\theta$ using **Proximal Policy Optimization (PPO)** is notoriously complex because it requires orchestrating **four separate neural network models in GPU memory simultaneously**:

```text
                               The 4 Models in PPO Training
                               
                    Prompt x
                       │
       ┌───────────────┴───────────────┐
       ▼                               ▼
 ┌──────────────┐                ┌──────────────┐
 │ Actor Model  │ (Active)       │ Ref Model    │ (Frozen)
 │    π_θ       │                │    π_ref     │
 └──────┬───────┘                └──────┬───────┘
        │ Generates y                   │
        ├───────────────────────────────┤ ──► Computes KL Divergence Penalty
        ▼                               ▼     D_KL(π_θ || π_ref)
 ┌──────────────┐                ┌──────────────┐
 │ Reward Model │ (Frozen)       │ Value Model  │ (Active)
 │    r_ψ       │                │    V_ϕ       │
 └──────┬───────┘                └──────┬───────┘
        │ Scores (x, y)                 │ Predicts Expected Returns
        ▼                               ▼
 ┌──────────────────────────────────────────────┐
 │ Combined Objective = r_ψ(x, y) - β * D_KL    │
 └──────────────────────┬───────────────────────┘
                        │
                        ▼
           PPO Policy Gradient Update
```

#### The Composite PPO Objective Function
The RLHF objective maximizes expected reward while penalizing the **Kullback-Leibler (KL) divergence** between the current policy $\pi_\theta$ and the initial frozen reference policy $\pi_{\text{ref}}$:

$$\max_{\theta} \mathbb{E}_{(x, y) \sim \mathcal{D}_{\pi_\theta}} \left[ r_\psi(x, y) - \beta \, D_{\text{KL}}\left(\pi_\theta(y \mid x) \,\|\, \pi_{\text{ref}}(y \mid x)\right) \right]$$

Where:
- $r_\psi(x, y)$: The scalar preference score output by the reward model.
- $\beta$: The KL coefficient controlling the strength of the penalty.
- $D_{\text{KL}}$: Ensures the model does not drift too far from natural language distributions.

---

### Why the KL Penalty is Critical: Combatting "Reward Hacking"

Without the KL penalty ($\beta = 0$), RLHF inevitably collapses due to **Goodhart's Law**: *"When a metric becomes a target, it ceases to be a good metric."*

In language models, this manifests as **Reward Hacking**:
1. **Gibberish Exploits:** The policy model discovers strange strings of punctuation or repetition that trigger anomalously high scores in the imperfect Reward Model.
2. **Extreme Verbosity:** The model generates 3,000-word encyclopedic essays for simple yes/no questions because the reward model equates length with effort.
3. **Mode Collapse:** The model collapses into generating a handful of rigid, formulaic responses regardless of the query.

The KL term acts as an elastic tether anchored to $\pi_{\text{ref}}$, ensuring the model remains fluent, coherent, and grounded.

---

### Key Point

> **RLHF aligns language models with human values through a 3-step pipeline: SFT baseline training, Reward Model training via Bradley-Terry pair ranking, and PPO policy optimization. Crucially, a KL-divergence penalty is enforced against a frozen reference model to prevent reward hacking and policy collapse.**

---

### Interview Answer

> "Reinforcement Learning from Human Feedback (RLHF) is an alignment framework that optimizes an LLM's outputs against human preference rankings rather than simple cross-entropy.
> 
> The pipeline consists of three phases:
> 1. Training a baseline SFT model.
> 2. Training a scalar **Reward Model** on human preference pairs $(x, y_w, y_l)$ using the Bradley-Terry loss function.
> 3. Optimizing the language model using **PPO (Proximal Policy Optimization)**.
> 
> PPO requires coordinating four networks simultaneously: the Actor (policy being updated), the Critic (value baseline), the frozen Reward Model, and the frozen Reference Model. A KL-divergence penalty between the actor and the reference model is essential to prevent reward hacking, where the policy exploits flaws in the reward model to produce verbose or pathological responses."
