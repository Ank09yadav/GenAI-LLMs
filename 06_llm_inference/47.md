## 47. What is top-p (nucleus) sampling?

### Answer

**Top-P Sampling** (also known as **Nucleus Sampling**), introduced by Holtzman et al. (ICLR 2020), is an adaptive decoding strategy that samples from the smallest set of top-ranked tokens whose cumulative probability mass exceeds a specified threshold $p \in (0, 1]$.

Unlike Top-K sampling—which statically forces the candidate pool to a constant size $K$—Top-P allows the candidate pool size to **dynamically expand and contract** at every generation step based on the model's confidence and the entropy of the context.

```text
                               The Nucleus (Top-P) Sampling Mechanism
                               
 High-Confidence Context (Low Entropy):             Low-Confidence Context (High Entropy):
 Prompt: "The capital of France is"                 Prompt: "The mysterious traveler opened the"
 ┌──────────────────────────────────────┐           ┌──────────────────────────────────────┐
 │ Token        Prob     CumSum         │           │ Token        Prob     CumSum         │
 │ "Paris"      0.96     0.96 (>= 0.90!)│ ◄─ STOP   │ "door"       0.28     0.28           │
 │ "Lyon"       0.02     0.98           │           │ "chest"      0.22     0.50           │
 │ "the"        0.01     0.99           │           │ "letter"     0.18     0.68           │
 └──────────────────────────────────────┘           │ "package"    0.15     0.83           │
 Result for p = 0.90:                               │ "book"       0.10     0.93 (>= 0.90!)│ ◄─ STOP
 Candidate Pool automatically collapses to          └──────────────────────────────────────┘
 EXACTLY 1 TOKEN: {"Paris"}                         Result for p = 0.90:
                                                    Candidate Pool automatically expands to
                                                    5 TOKENS: {"door", "chest", "letter", ...}
```

### Step-by-Step Mathematical Algorithm

At generation step $t$:
1. Compute the raw logit vector $\mathbf{z} \in \mathbb{R}^{|V|}$ and evaluate base probabilities:
   $$P(x_i) = \frac{\exp(z_i)}{\sum_{j=1}^{|V|} \exp(z_j)}$$
2. Sort vocabulary tokens in descending order of probability:
   $$P(x_{(1)}) \ge P(x_{(2)}) \ge \dots \ge P(x_{(|V|)})$$
3. Determine the dynamic index cutoff $k$ such that the cumulative probability mass reaches threshold $p$:
   $$V^{(p)} = \{ x_{(1)}, x_{(2)}, \dots, x_{(k)} \} \quad \text{where } k = \min \left\{ m \in \{1, \dots, |V|\} : \sum_{i=1}^{m} P(x_{(i)}) \ge p \right\}$$
4. Set the probabilities of all tokens outside the nucleus $V^{(p)}$ to zero:
   $$P'(x_i) = \begin{cases} \frac{P(x_i)}{\sum_{x \in V^{(p)}} P(x)} & \text{if } x_i \in V^{(p)} \\ 0 & \text{otherwise} \end{cases}$$
5. Sample the next token from the renormalized distribution $P'$.

---

### Why Nucleus Sampling Outperforms Top-K

Holtzman et al. discovered that human text generation does not align with uniform stochastic sampling or static truncation. In natural language:
- When a thought is factual and obvious, the true distribution is **concentrated in a small nucleus** of 1–2 words.
- When an idea is open-ended or poetic, the distribution **flattens out across dozens of valid lexical choices**.

| Feature | Top-K Sampling | Top-P (Nucleus) Sampling |
| :--- | :--- | :--- |
| **Threshold Type** | Static integer count ($K \in \mathbb{N}$) | Dynamic cumulative probability ($p \in (0, 1]$) |
| **Adaptability to Entropy**| Poor (rigid pool regardless of model confidence) | **Optimal** (dynamically resizes candidate set) |
| **Factual Prompts** | Retains low-scoring erroneous tokens if $K$ is large | Automatically shrinks pool to 1 or 2 tokens |
| **Creative Prompts** | Truncates valid lexical choices if $K$ is small | Expands pool to capture diverse synonyms |
| **Typical Production Value**| $K = 40$ | $p = 0.90 \text{ or } 0.95$ |

### The Full Inference Pipeline in Production

In high-performance inference engines (e.g., vLLM, TensorRT-LLM), decoding parameters are applied in a strict sequential pipeline:

```text
 ┌──────────────┐      ┌─────────────────────────┐      ┌────────────────────────┐
 │ Raw Logits z │ ───► │ Temperature: z_scaled   │ ───► │ Repetition Penalties   │
 └──────────────┘      │ z_i = z_i / T           │      │ Frequency / Presence   │
                       └─────────────────────────┘      └──────────┬─────────────┘
                                                                   │
                                                                   ▼
 ┌──────────────┐      ┌─────────────────────────┐      ┌────────────────────────┐
 │ Sample Next  │ ◄─── │ Renormalize via Softmax │ ◄─── │ Top-K & Top-P Truncate │
 │ Output Token │      │ P'(x_i) over nucleus    │      │ Mask unselected to -∞  │
 └──────────────┘      └─────────────────────────┘      └────────────────────────┘
```

When both Top-K and Top-P are enabled, the engine first cuts off candidates beyond rank $K$, and then applies the cumulative probability cutoff $p$ on the remaining set.

---

### Key Point

> **Top-P (Nucleus) sampling dynamically truncates the vocabulary by selecting the smallest subset of top tokens whose cumulative probability mass meets or exceeds threshold $p$. This provides adaptive entropy management: shrinking to a single token when confidence is absolute, and expanding to many candidates during open-ended dialogue.**

### Interview Answer

> "Top-P, or Nucleus Sampling, is an adaptive decoding algorithm introduced by Holtzman et al. to eliminate the static limitations of Top-K. 
> 
> Rather than truncating candidates to a static integer count, Top-P sorts the vocabulary by descending probability and samples exclusively from the dynamic 'nucleus'—the smallest subset of top tokens whose cumulative probability sum meets or exceeds a target threshold $p$ (typically $0.90$ or $0.95$).
> 
> The core advantage of Top-P is its automatic adaptation to contextual entropy: in low-entropy factual contexts (e.g., 'The capital of France is...'), the cumulative threshold is satisfied by a single token ('Paris'), preventing hallucinated tail words. In high-entropy narrative contexts, the nucleus expands to dozens of candidate tokens, preserving natural linguistic variation."
