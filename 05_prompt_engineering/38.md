## 38. What is chain-of-thought prompting?

### Answer

**Chain-of-Thought (CoT) Prompting**, introduced by Wei et al. (Google Research, 2022), is a prompting strategy that encourages Large Language Models to decompose complex, multi-step problems into explicit intermediate rationales before producing a final answer.

Rather than forcing the model to jump directly from input query to final output, CoT provides a token-based **computational scratchpad**.

```text
                                Direct Prompting vs. Chain-of-Thought
                                
 Direct Prompting (Constant-Compute Bottleneck):
 ┌────────────────────────────────────────────────────────┐
 │ Input: "Roger has 5 tennis balls. He buys 2 cans of    │
 │ tennis balls. Each can has 3 balls. How many does he   │
 │ have now?"                                             │
 └──────────────────────────┬─────────────────────────────┘
                            │ Single forward pass to generate answer
                            ▼
 ┌────────────────────────────────────────────────────────┐
 │ Output: "Roger has 10 tennis balls." (WRONG: Hallucinated directly) │
 └────────────────────────────────────────────────────────┘
 
 Chain-of-Thought Prompting (Autoregressive Scratchpad Computation):
 ┌────────────────────────────────────────────────────────┐
 │ Output:                                                │
 │ "Let's think step by step:                             │
 │ 1. Roger starts with 5 tennis balls.                   │  ◄── Intermediate Token 1
 │ 2. He buys 2 cans of 3 tennis balls each = 2 * 3 = 6.  │  ◄── Intermediate Token 2
 │ 3. 5 + 6 = 11 tennis balls.                            │  ◄── Intermediate Token 3
 │ Therefore, the answer is 11." (CORRECT)                │  ◄── Final Answer
 └────────────────────────────────────────────────────────┘
```

---

### The Underlying Computational Mechanism: Why Does CoT Work?

A fundamental architectural constraint of standard Transformers is that **each generated token receives a fixed amount of computation**: exactly one forward pass through $L$ layers. 

If a user demands an immediate answer to a 5-step mathematical puzzle in zero steps, the model must compress all 5 reasoning operations into the single forward pass of the first output token. This is computationally impossible for non-trivial logic.

```text
                 The Transformer Token-Compute Relationship
                 
 Monolithic Response:
 [Prompt] ──► [Layer 1..L] ──► Output: "11"  (Attempting 5 reasoning steps in 1 pass!)
 
 Chain-of-Thought Generation:
 [Prompt] ──► [Layer 1..L] ──► Output: "Starts with 5"  (Step 1 computed)
     │
     ▼ (Self-Attention Attends to Step 1)
 [Context + Step 1] ──► [Layer 1..L] ──► Output: "2 * 3 = 6"  (Step 2 computed)
     │
     ▼ (Self-Attention Attends to Steps 1 & 2)
 [Context + Steps 1 & 2] ──► [Layer 1..L] ──► Output: "5 + 6 = 11" (Final deduction)
```

By generating intermediate tokens, the model **allocates more total FLOPs** to the problem. Every intermediate token performs an additional forward pass, and subsequent tokens attend back to those intermediate calculations via self-attention!

### The Flavors of Chain-of-Thought

```text
 ┌─────────────────────────────────────────────────────────────────────────────────────────────┐
 │ 1. Zero-Shot CoT (Kojima et al., 2022)                                                      │
 │ Simply append the trigger phrase: "Let's think step by step."                               │
 ├─────────────────────────────────────────────────────────────────────────────────────────────┤
 │ 2. Few-Shot CoT (Wei et al., 2022)                                                          │
 │ Provide 2-3 exemplars where demonstrations explicitly write out the rationale sentences.    │
 ├─────────────────────────────────────────────────────────────────────────────────────────────┤
 │ 3. Self-Consistency CoT (Wang et al., 2022)                                                 │
 │ Sample multiple CoT paths (e.g., N=10) with Temperature = 0.7, then take a majority vote!   │
 ├─────────────────────────────────────────────────────────────────────────────────────────────┤
 │ 4. Tree of Thoughts (ToT, Yao et al., 2023)                                                 │
 │ Explores multiple reasoning branches, evaluates intermediate states, and backtracks via BFS │
 └─────────────────────────────────────────────────────────────────────────────────────────────┘
```

---

### Self-Consistency: Majority Voting over Reasoning Paths

The single most effective way to boost reasoning accuracy on complex tasks without fine-tuning is **Self-Consistency**:

```text
                                Self-Consistency Mechanism
                                
                                     User Question
                                           │
                ┌──────────────────────────┼──────────────────────────┐
                ▼                          ▼                          ▼
          Path 1 (T=0.7)             Path 2 (T=0.7)             Path 3 (T=0.7)
         Reasoning Chain            Reasoning Chain            Reasoning Chain
                │                          │                          │
          Answer: "$450"             Answer: "$450"             Answer: "$520"
                └──────────────────────────┬──────────────────────────┘
                                           │
                                           ▼
                                 Majority Vote Decision
                                    Winner: "$450" (67% consensus)
```

By sampling 5 to 40 reasoning trajectories and aggregating the final answers, random stochastic errors and early reasoning slips get filtered out by consensus.

---

### The Evolution: From Prompting to Native "System 2" Reasoning Models

In modern frontier AI (e.g., OpenAI o1/o3, DeepSeek-R1), Chain-of-Thought has evolved from an external prompt engineering trick into an **intrinsic test-time compute mechanism**:
- These models are trained using **Reinforcement Learning** to generate long, internal reasoning tokens (hidden thinking chains) before outputting the user-facing response.
- The model learns to backtrack, verify its own work, double-check arithmetic, and explore alternative hypotheses autonomously during inference.

---

### Key Point

> **Chain-of-Thought prompting prompts an LLM to generate explicit intermediate reasoning steps prior to giving a final answer. Mechanistically, this allows the Transformer to allocate additional FLOPs and forward passes to complex problems, enabling self-attention to condition the final answer on verified intermediate logic.**

### Interview Answer

> "Chain-of-Thought (CoT) prompting is a technique where an LLM is prompted to produce step-by-step intermediate reasoning before outputting the final answer. 
> 
> Mechanistically, because each token generated by a Transformer receives an identical, fixed computational budget ($O(1)$ layers per token), demanding an immediate answer to a complex multi-step question forces the model to compress all computational steps into a single forward pass. CoT acts as a dynamic computational scratchpad: each reasoning token generated executes an additional forward pass through the network, allowing subsequent tokens to attend back to verified intermediate calculations. 
> 
> Beyond zero-shot CoT ('Let's think step by step'), techniques like Self-Consistency sample multiple reasoning paths to take a majority vote, and frontier reasoning models (like OpenAI o1 or DeepSeek-R1) train models to perform internal test-time reasoning natively via reinforcement learning."
