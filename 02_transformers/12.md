## 12. How does self-attention work?

### Answer

**Self-Attention** (also called intra-attention) is a mechanism that allows each token in an input sequence to dynamically attend to, score, and aggregate contextual information from every other token in the same sequence based on semantic and syntactic relevance.

The canonical formula defined in Vaswani et al. is **Scaled Dot-Product Attention**:

$$\operatorname{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \operatorname{softmax}\left(\frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d_k}} + \mathbf{M}\right) \mathbf{V}$$

where $\mathbf{Q}, \mathbf{K}, \mathbf{V}$ are the Query, Key, and Value matrices, $d_k$ is the dimensionality of the key vectors, and $\mathbf{M}$ is an optional attention mask.

```text
                  Scaled Dot-Product Attention Flow
                  
             Queries (Q)          Keys (K)
                  │                  │
                  └───► MatMul ◄─────┘
                           │
                           ▼
                    Raw Scores (Q K^T)  [Shape: N x N]
                           │
                           ▼
                   Scale (÷ √d_k)
                           │
                           ▼
                Apply Causal Mask (M)  [Set future tokens to -inf]
                           │
                           ▼
                        Softmax         [Attention Weights A, rows sum to 1.0]
                           │
                           ▼
                       MatMul ◄───── Values (V) [Shape: N x d_v]
                           │
                           ▼
                     Context Output     [Shape: N x d_v]
```

---

### Step-by-Step Mathematical Derivation

#### Step 1: Linear Projections
Given an input sequence representation matrix $\mathbf{X} \in \mathbb{R}^{N \times d_{\text{model}}}$, we compute the three projections:
$$\mathbf{Q} = \mathbf{X} \mathbf{W}_Q, \quad \mathbf{K} = \mathbf{X} \mathbf{W}_K, \quad \mathbf{V} = \mathbf{X} \mathbf{W}_V$$
where $\mathbf{W}_Q, \mathbf{W}_K \in \mathbb{R}^{d_{\text{model}} \times d_k}$ and $\mathbf{W}_V \in \mathbb{R}^{d_{\text{model}} \times d_v}$.

#### Step 2: Pairwise Score Matrix ($\mathbf{Q} \mathbf{K}^T$)
Multiply the Query matrix by the transpose of the Key matrix:
$$\mathbf{S} = \mathbf{Q} \mathbf{K}^T \in \mathbb{R}^{N \times N}$$
Each entry $S_{ij}$ is the scalar dot product between the Query of token $i$ and the Key of token $j$:
$$S_{ij} = \mathbf{q}_i \cdot \mathbf{k}_j^T = \sum_{m=1}^{d_k} q_{i,m} k_{j,m}$$

#### Step 3: Variance Scaling by $\frac{1}{\sqrt{d_k}}$ (Why Divide by $\sqrt{d_k}$?)
Why is this scaling factor essential?
- Assume components of $\mathbf{q}$ and $\mathbf{k}$ are independent random variables with mean $0$ and variance $1$.
- The dot product is $\sum_{m=1}^{d_k} q_m k_m$.
- By the properties of independent random variables:
  $$\mathbb{E}[q_m k_m] = 0, \quad \operatorname{Var}(q_m k_m) = \operatorname{Var}(q_m) \operatorname{Var}(k_m) = 1$$
  $$\operatorname{Var}\left(\sum_{m=1}^{d_k} q_m k_m\right) = \sum_{m=1}^{d_k} \operatorname{Var}(q_m k_m) = \mathbf{d_k}$$
- For large dimensions (e.g., $d_k = 64$ or $128$), the variance of the dot product is $64$ or $128$ (standard deviation $8$ to $11.3$).
- This causes raw scores $S_{ij}$ to have very large magnitudes, pushing the **softmax function into extreme saturation regions where gradients are practically zero ($\approx 0$)**, causing training to stall.
- Dividing by $\sqrt{d_k}$ scales variance back to **$1.0$**, preserving healthy gradient dynamics.

#### Step 4: Causal Masking (In Autoregressive Decoders)
For causal language modeling, token $i$ must not attend to future tokens $j > i$. Future positions are set to $-\infty$:
$$M_{ij} = \begin{cases} 0 & \text{if } j \le i \\ -\infty & \text{if } j > i \end{cases}$$
When passed through softmax, $\exp(-\infty) = 0$, guaranteeing that no information flows backward from the future.

```text
Causal Mask Matrix Visualization:
       T1      T2      T3      T4
T1 [    0    -inf    -inf    -inf ]   ──► Softmax ──► [ 1.00  0.00  0.00  0.00 ]
T2 [    0       0    -inf    -inf ]   ──► Softmax ──► [ 0.45  0.55  0.00  0.00 ]
T3 [    0       0       0    -inf ]   ──► Softmax ──► [ 0.20  0.30  0.50  0.00 ]
T4 [    0       0       0       0 ]   ──► Softmax ──► [ 0.10  0.15  0.25  0.50 ]
(Token 4 sees tokens 1..4; Token 1 can only see itself!)
```

#### Step 5: Softmax Normalization
Compute attention weights $\mathbf{A} \in \mathbb{R}^{N \times N}$:
$$\mathbf{A} = \operatorname{softmax}\left(\frac{\mathbf{S}}{\sqrt{d_k}} + \mathbf{M}\right)$$
Each row of $\mathbf{A}$ represents a valid categorical probability distribution summing to $1.0$.

#### Step 6: Value Aggregation
Multiply attention weights by the Value matrix $\mathbf{V}$:
$$\mathbf{Output} = \mathbf{A} \mathbf{V} \in \mathbb{R}^{N \times d_v}$$
The final representation of each token is now a contextualized blend of all preceding values in the sequence.

### Concrete PyTorch Implementation: Scaled Dot-Product Attention

```python
import torch
import torch.nn as nn
import math

def scaled_dot_product_attention(Q: torch.Tensor, K: torch.Tensor, V: torch.Tensor, is_causal: bool = True):
    """
    Q, K, V shape: [batch_size, num_heads, seq_len, head_dim]
    """
    d_k = Q.size(-1)
    
    # 1. Compute raw scores: [B, H, N, d_k] x [B, H, d_k, N] -> [B, H, N, N]
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    
    # 2. Apply causal mask if required
    if is_causal:
        seq_len = Q.size(-2)
        # Upper triangular mask with diagonal=1
        mask = torch.triu(torch.full((seq_len, seq_len), float('-inf'), device=Q.device), diagonal=1)
        scores = scores + mask
        
    # 3. Softmax along last dimension (over keys)
    attention_weights = torch.softmax(scores, dim=-1)
    
    # 4. Multiply by Values: [B, H, N, N] x [B, H, N, d_v] -> [B, H, N, d_v]
    output = torch.matmul(attention_weights, V)
    
    return output, attention_weights

# Example forward verification:
B, H, N, D = 2, 4, 8, 64
q, k, v = torch.randn(B, H, N, D), torch.randn(B, H, N, D), torch.randn(B, H, N, D)
out, weights = scaled_dot_product_attention(q, k, v, is_causal=True)
print("Output shape:", out.shape)       # [2, 4, 8, 64]
print("Weights shape:", weights.shape)  # [2, 4, 8, 8]
```

### Key Point

> **Self-attention projects tokens to Query, Key, and Value spaces, calculates scaled pairwise compatibility scores ($\frac{QK^T}{\sqrt{d_k}}$), applies causal masking, and computes a softmax-weighted sum over Value vectors.**

---

### Interview Answer

> **Self-attention allows every token in an input sequence to dynamically route and aggregate information from every other token. 
> 
> It operates through six mathematical stages:
> 1. Ingesting input embeddings and projecting them into Query, Key, and Value matrices ($\mathbf{Q}, \mathbf{K}, \mathbf{V}$) using learned linear weights.
> 2. Computing the pairwise dot product between all Queries and Keys ($\mathbf{Q}\mathbf{K}^T$) to form an $N \times N$ similarity matrix.
> 3. Scaling the matrix by $\frac{1}{\sqrt{d_k}}$ to maintain unit variance and prevent the softmax function from saturating into regions with vanishing gradients.
> 4. In autoregressive decoders, applying an upper-triangular causal mask of $-\infty$ so tokens cannot attend to future positions.
> 5. Normalizing scores via softmax across rows so that attention weights sum to 1.0.
> 6. Multiplying the attention weight matrix by the Value matrix $\mathbf{V}$, producing enriched contextualized token representations.**
