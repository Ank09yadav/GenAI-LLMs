## 15. What is the difference between encoder-only, decoder-only, and encoder-decoder Transformers?

### Answer

Transformer architectures are classified into three distinct architectural archetypes based on their **attention masking strategies, information flow directions, and pretraining objectives**:

```text
                     The Three Transformer Architectural Archetypes
                     
1. Encoder-Only (e.g., BERT, RoBERTa, DeBERTa):
   [Token 1] ◄────────► [Token 2] ◄────────► [Token 3] ◄────────► [Token 4]
   (Bidirectional Attention: Every token sees all past and future tokens simultaneously)

2. Decoder-Only (e.g., GPT-4, LLaMA-3, Mistral, Claude):
   [Token 1] ─────────► [Token 2] ─────────► [Token 3] ─────────► [Token 4]
   (Causal Masked Attention: Token i can only attend to tokens <= i)

3. Encoder-Decoder (e.g., T5, BART, MarianMT):
   Encoder (Bidirectional on Source) ──► Cross-Attention ──► Decoder (Causal on Target)
   "Translate French Input Text"                              "Generate English Output"
```

---

### Attention Masking: The Core Mathematical Difference

The mathematical divergence between the three archetypes is governed by the **Attention Mask Matrix ($\mathbf{M}$)** added to raw scores before softmax:

$$\mathbf{A} = \operatorname{softmax}\left(\frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d_k}} + \mathbf{M}\right)$$

```text
Encoder Bidirectional Mask:               Decoder Causal Mask:
(All tokens see all tokens)               (Tokens only see past & present)
       T1    T2    T3    T4                      T1    T2    T3    T4
T1 [    0     0     0     0 ]             T1 [    0  -inf  -inf  -inf ]
T2 [    0     0     0     0 ]             T2 [    0     0  -inf  -inf ]
T3 [    0     0     0     0 ]             T3 [    0     0     0  -inf ]
T4 [    0     0     0     0 ]             T4 [    0     0     0     0 ]
```

### Comprehensive 10-Dimension Technical Comparison

| Dimension | Encoder-Only | Decoder-Only | Encoder-Decoder |
| :--- | :--- | :--- | :--- |
| **Canonical Models** | BERT, RoBERTa, DeBERTa | GPT-4, LLaMA-3, Mistral, Claude | T5, BART, Flan-T5, MarianMT |
| **Attention Pattern** | **Bidirectional:** Unconstrained attention across all tokens. | **Causal:** Lower-triangular mask; tokens attend strictly to past tokens. | Bidirectional in Encoder; Causal in Decoder + Cross-Attention. |
| **Pretraining Objective**| **Masked Language Modeling (MLM):** Predict randomly masked tokens (`[MASK]`). | **Causal Language Modeling (CLM):** Autoregressive next-token prediction. | **Span Corruption / Denoising:** Reconstruct masked multi-token spans. |
| **Primary Strength** | Deep, holistic bidirectional semantic representation. | Open-ended generation, reasoning, in-context few-shot learning. | Sequence-to-sequence translation, conditioned summarization. |
| **Inference Mechanism**| Single forward pass across entire sequence. | Iterative autoregressive loop (one token per forward pass). | Encoder runs once; Decoder runs autoregressive loop. |
| **KV Cache Required?** | **No.** Forward pass evaluates all tokens concurrently. | **Yes.** Mandatory for efficient autoregressive generation. | **Yes.** Decoder requires self-attention and cross-attention caches. |
| **Generative Ability** | Poor / Ineffective. | **Exceptional.** Universal generative intelligence. | High for bounded input-to-output transformations. |
| **Classification Fit** | **Superior & Cost-Effective.** | Effective but computationally overkill. | Effective but complex deployment. |
| **Dense Embeddings Fit**| **Optimal.** Used in modern embedding models (BGE, E5). | Requires specialized contrastive fine-tuning. | Suboptimal. |
| **Latency Profile** | Ultra-low latency ($< 10\text{ms}$). | Latency scales with generated token count. | Moderate latency. |

### In-Depth Architectural Archetype Breakdown

#### 1. Encoder-Only Architectures (BERT Paradigm)
- **Mechanism:** Ingests the full sentence and computes bidirectional attention representations.
- **Pretraining (MLM):** $15\%$ of tokens are replaced with `[MASK]`. The model predicts masked words using both left and right context:
  $$\text{Input: "The [MASK] sat on the mat."} \implies \text{Target: "cat"}$$
- **Best Production Use Cases:**
  - High-throughput sentiment classification (fraud detection, spam filtering).
  - Named Entity Recognition (NER) and token labeling.
  - Generating dense vector embeddings for semantic search in vector databases.

#### 2. Decoder-Only Architectures (GPT / LLaMA Paradigm)
- **Mechanism:** Uses causal masking to prevent attention to future tokens.
- **Pretraining (CLM):** Predicts the next token $x_t$ given $x_{<t}$.
- **Best Production Use Cases:**
  - Conversational AI and autonomous agentic workflows.
  - Creative copywriting, reasoning, and multi-step logic.
  - Code synthesis, refactoring, and debugging.

#### 3. Encoder-Decoder Architectures (T5 Paradigm)
- **Mechanism:** Decouples input comprehension from output generation. The encoder builds unconstrained bidirectional representations of source text, and the decoder generates target text conditioned on encoder states via **Cross-Attention**:
  $$\mathbf{Q} = \mathbf{H}_{\text{decoder}} \mathbf{W}_Q, \quad \mathbf{K} = \mathbf{H}_{\text{encoder}} \mathbf{W}_K, \quad \mathbf{V} = \mathbf{H}_{\text{encoder}} \mathbf{W}_V$$
- **Best Production Use Cases:**
  - Direct language translation (e.g., French $\to$ English).
  - Document abstractive summarization.

---

### Key Point

> **Encoder-only models excel at bidirectional understanding and dense embeddings; Encoder-Decoder models excel at sequence-to-sequence translation; Decoder-only models dominate generative AI due to pretraining simplicity and unified in-context reasoning.**

---

### Interview Answer

> **The distinction between Transformer archetypes is rooted in their attention masking patterns and pretraining objectives:
> 
> 1. **Encoder-Only Models (e.g., BERT):** Utilize unconstrained bidirectional self-attention where every token attends to all past and future tokens. Trained via Masked Language Modeling (MLM), they produce superior holistic representations, making them the industry standard for classification, Named Entity Recognition, and dense semantic embeddings.
> 2. **Decoder-Only Models (e.g., GPT, LLaMA):** Employ lower-triangular causal attention masking to prevent tokens from attending to future positions. Trained on autoregressive next-token prediction, they excel at open-ended generation, reasoning, and zero-shot in-context learning, and currently dominate the generative AI landscape.
> 3. **Encoder-Decoder Models (e.g., T5):** Combine a bidirectional encoder for source context with a causally masked decoder utilizing cross-attention over encoder outputs. They are specifically optimized for sequence transduction tasks like translation and strict document summarization.**
