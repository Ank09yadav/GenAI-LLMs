## 10. What is the Transformer architecture?

### Answer

The **Transformer architecture** is a deep neural network that processes sequential data by modeling all-to-all relationships between tokens purely through **attention mechanisms, point-wise feed-forward networks, and residual normalizations**, eliminating all recurrent and convolutional operations.

While originally introduced as an **Encoder-Decoder** for sequence transduction (machine translation), the architecture has evolved into modern **Decoder-Only** architectures (e.g., LLaMA-3, Mistral, GPT-4) that power generative language modeling.

```text
                     Modern Decoder-Only Transformer Block
                     
                     Output of Layer l
                             ▲
                             │
                     Add ( + ) Residual Highway
                     ┌───────┴───────┐
                     │               │
                     │       [Feed-Forward Network (MLP)]
                     │       SwiGLU: Swish(x * W_gate) * (x * W_up) * W_down
                     │               ▲
                     │               │
                     │       [RMSNorm / LayerNorm]
                     │               ▲
                     └───────┬───────┘
                             │
                     Add ( + ) Residual Highway
                     ┌───────┴───────┐
                     │               │
                     │       [Causal Multi-Head / Grouped-Query Attention]
                     │       Softmax((Q * K^T) / sqrt(d_k) + M) * V
                     │       (with Rotary Positional Embeddings - RoPE)
                     │               ▲
                     │               │
                     │       [RMSNorm / LayerNorm]
                     │               ▲
                     └───────┬───────┘
                             │
                     Input to Layer l (Hidden State h_{l-1})
```

### The Core Architectural Sub-Layers

#### 1. Input Embeddings and Positional Encoding
Discrete token IDs are projected into continuous vectors of dimension $d_{\text{model}}$ via an embedding lookup matrix $\mathbf{W}_{\text{embed}} \in \mathbb{R}^{|V| \times d_{\text{model}}}$. Because self-attention is permutation-invariant, positional coordinates are injected via **Rotary Position Embeddings (RoPE)** or additive sinusoidal vectors.

#### 2. Multi-Head Self-Attention (MHA / GQA)
Maps token representations into multiple lower-dimensional subspaces using projection matrices $\mathbf{W}_Q, \mathbf{W}_K, \mathbf{W}_V$. Computes pairwise affinities between all tokens up to the current position (using a lower-triangular causal mask $\mathbf{M}$ in decoders) and outputs a context-weighted blend of Value vectors:

$$\operatorname{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \operatorname{softmax}\left(\frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d_k}} + \mathbf{M}\right) \mathbf{V}$$

#### 3. Position-Wise Feed-Forward Network (FFN / MLP)
Applied identically and independently to each token position. In modern foundation models, the classic 2-layer ReLU MLP has been replaced by the **SwiGLU (Swish Gated Linear Unit)** activation (Shazeer, 2020):

$$\operatorname{SwiGLU}(\mathbf{x}) = \left(\operatorname{Swish}(\mathbf{x} \mathbf{W}_{\text{gate}}) \otimes (\mathbf{x} \mathbf{W}_{\text{up}})\right) \mathbf{W}_{\text{down}}$$

where $\otimes$ denotes element-wise multiplication. The FFN accounts for approximately **$65\%-70\%$ of the model's total non-embedding parameters** and functions as the model's primary associative memory store.

#### 4. Residual Skip Connections & Normalization
Every sub-layer is wrapped in a residual skip connection:
$$\mathbf{x}_{\text{out}} = \mathbf{x} + \operatorname{SubLayer}(\operatorname{Norm}(\mathbf{x}))$$
Residual connections create an unobstructed gradient highway during backpropagation, allowing gradients to propagate directly through 100+ stacked layers without attenuation.

### Pre-LN vs. Post-LN: The Architectural Shift

The placement of layer normalization within the Transformer block underwent a crucial evolution that enabled training models beyond 100 layers:

```text
Post-LN (Original 2017 Transformer):
Input ──► [SubLayer] ──► [Add: x + SubLayer(x)] ──► [LayerNorm] ──► Output
- Problem: Gradients passing through the residual connection are repeatedly scaled by LayerNorm.
  In deep networks, gradients vanish or explode at early layers, requiring delicate learning rate
  warmup schedules and careful initialization.

Pre-LN (Modern LLMs: LLaMA, GPT-3, Mistral):
Input ──► [LayerNorm] ──► [SubLayer] ──► [Add: x + SubLayer(Norm(x))] ──► Output
          │                                        ▲
          └────────────────────────────────────────┘
- Advantage: The residual connection forms a clean, unnormalized identity highway (x + F(x)).
  Gradients flow directly to early layers without distortion, allowing stable training of
  massive 70B+ models from the very first step.
```

---

### LayerNorm vs. RMSNorm

Modern frontier models (LLaMA-3, Mistral, Gemma) replace standard Layer Normalization with **Root Mean Square Normalization (RMSNorm - Zhang & Sennrich, 2019)**:

- **Standard LayerNorm:** Re-centers and re-scales using mean $\mu$ and variance $\sigma^2$:
  $$\operatorname{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta$$
- **RMSNorm:** Discards the mean-centering step entirely, scaling strictly by root mean square:
  $$\operatorname{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d} \sum_{i=1}^d x_i^2 + \epsilon}} \odot \gamma$$

**Benefit:** Discarding mean calculation reduces GPU memory traffic, delivering a **$10\%-15\%$ speedup in wall-clock layer computation** with zero degradation in empirical model performance.

---

### Key Point

> **The Transformer architecture alternates multi-head attention (token communication) with gated feed-forward networks (associative feature processing), connected by residual highways and Pre-Layer/RMS normalization to ensure gradient stability in deep networks.**

### Interview Answer

> **The Transformer architecture is a deep neural network composed of stacked identical blocks combining attention mechanisms, position-wise feed-forward networks, and residual normalizations.
> 
> In modern generative LLMs, the architecture has converged on a **Decoder-Only Pre-LN design**:
> 1. **Token Embeddings & RoPE:** Tokens are mapped to continuous vectors and rotated by Rotary Position Embeddings to encode relative distance.
> 2. **Causal Attention:** Multi-Head or Grouped-Query Attention dynamically routes context between tokens while a triangular causal mask preserves autoregression.
> 3. **SwiGLU Feed-Forward Networks:** Gated linear units process per-token representations, acting as the primary associative memory of the network.
> 4. **Pre-RMSNorm and Residuals:** Normalizing inputs before each sub-layer and utilizing unencumbered residual highways ensures smooth gradient propagation, allowing stable training across hundreds of layers and billions of parameters.**
